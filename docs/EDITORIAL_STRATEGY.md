# Editorial Strategy — Engineering Knowledge Hub

> Companion to `docs/adr/0002-two-plane-architecture.md` and the content model in
> `schema/post-metadata.schema.json`. Defines how the blog grows from a post
> stream into a navigable knowledge base.

## Content directions (taxonomy)

The site's niche (per README): industrial/systems engineering, data science,
decentralized systems. Map every post to one or more directions; the taxonomy
feeds `categories`, `tags`, and the Knowledge Graph concepts.

| Direction | `categories` value | Representative `tags` | Key concepts (KG) |
|-----------|--------------------|----------------------|-------------------|
| Industrial Engineering | `industrial` | `manufacturing`, `lean`, `automation` | process, throughput, control |
| Systems Engineering | `systems` | `architecture`, `reliability`, `modeling` | architecture, trade-off |
| Data Science | `data-science` | `ml`, `statistics`, `viz` | dataset, model |
| Decentralized Web | `decentralized` | `p2p`, `ipfs`, `protocol` | protocol, node |
| DAO Governance | `dao` | `governance`, `voting`, `token` | governance, quorum |
| Semantic Web | `semantic` | `rdf`, `schema-org`, `kg` | concept, relation |
| AI Agents | `ai` | `agent`, `llm`, `automation` | agent, tool |

`categories` MUST come from the enum in `schema/post-metadata.schema.json`;
`tags` are free-form but SHOULD align with the representative tags above so the
Knowledge Graph clusters coherently.

## People & Domini as public entities

- `content/people/*.md` — public profiles (e.g. collaborators, cited authors).
  Required frontmatter: `title`, `slug`, `description`. Link to posts via
  `authors` on the post and, where relevant, a `related` list in the person file.
- `content/domini/*.md` — first-party notes/projects. Required: `title`, `slug`,
  `date`. These feed the Domini node type in the Knowledge Graph.

## Series

Multi-part deep-dives use a `series` field in frontmatter (added to the schema
when adopted). Series index pages are generated by Hugo taxonomies; link parts
with `prev`/`next` where helpful.

## Author checklist before publish

1. Frontmatter passes `scripts/validate-frontmatter.cjs` (hard gate in CI).
2. `categories` ∈ schema enum; `tags` align with a direction above.
3. Add `aliases` for any legacy URL you want preserved.
4. Run `node scripts/ci-content-contract.cjs` locally to self-check.
5. Concepts used should appear (or be added) so the post joins the graph.

## Cadence

Aim for a steady rhythm over bursty uploads: ~2 posts/month, one deep-dive
series per quarter. Monthly digest can be assembled from the KG + RSS.
