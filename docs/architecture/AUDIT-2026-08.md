## Technical Debt (priority)

- **R1 (P1)** 5 planning dirs were duplicated; consolidated 2026-08-18 (this audit).
- **R2 (P1)** R&D CI shares the prod pipeline; Chromium steps (e2e) are perpetually red
  on NixOS runners and mask real failures. → isolate `test-rnd.yml` (TASK-C2).
- **R3 (P2)** Heavy JS: vendored `d3.v7.min.js` (~280KB), KG 3D, `sw.js` + worker.
  Lighthouse perf < 0.9 (Cycle 22 relaxed budgets to warn). → asset budget + lazy D3.
- **R4 (P2, RESOLVED in Cycle 29)**: `search.json` at repo root was a **dead Jekyll-era Liquid-template leftover** (invalid for Hugo, never published → 404). The real search index is Hugo/Blowfish `public/index.json` (4.35 MB, 384 entries, full corpus, `no-content entries: 0`). `src/modules/search-engine.js` and `src/services/pwa-service.js` fetched the dead `/search.json` → silently broken R&D search. Fixed: both now fetch `/index.json`; dead root `search.json` removed; `robots.txt` disallows `/index.json` for AI crawlers. (R&D `src/` is not in the prod build, so this only affected the experimental layer.)
- **R5 (P3)** `deploy-ipfs.yml` dead (keys compromised). → mark disabled / remove.
- **R6 (P4)** npm audit 42 vulns (10 high, 0 critical) — all dev/CI tooling
  (hardhat/lighthouse/puppeteer/undici); node_modules never ships. Surfaced by
  severity in Cycle 25, gate on `critical` only.
