_bosto digitizer_

## BOSTO

```
Section "InputClass"
        Identifier "Bosto 16HD"
        MatchUSBID "0ed1:7821"
        MatchDevicePath "/dev/input/event*"
        Driver "wacom"
        Option "Area" "0 0 17910 10240"
        Option "Threshold" "1" #optional, should reduce the lag on pressing the pen
EndSection

```
