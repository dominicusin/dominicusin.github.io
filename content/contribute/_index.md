Мы открыты для авторов и исследователей. Если вы хотите подсвоими знаниями в области инженерных систем, data science, decentralized technologies — присоединяйтесь.

## Как это работает

1. **Форкните** репозиторий
2. **Создайте** пост в `content/blog/`
3. **Отправьте** Pull Request
4. **Получите** награду после мержа

## Требования

- Оригинальный контент (не опубликованный ранее)
- Соответствие [content contract](/docs/content-contract/)
- Корректное оформление (front matter, изображения, ссылки)

## Награды

| Тип | Награда |
|-----|---------|
| Пост | 100 KNOW tokens |
| Серия постов | Soulbound Token (SBT) |
| Менторство | 500 KNOW tokens |
| Баг-репорт | 50 KNOW tokens |

## Менторство

Опытные авторы могут стать менторами для новых контрибьюторов. Подайте заявку через [GitHub Discussions](https://github.com/dominicusin/dominicusin.github.io/discussions).
