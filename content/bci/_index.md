Экспериментальный интерфейс мозг-компьютер (BCI) для управления сайтом с помощью EEG-гарнитуры (Muse, OpenBCI).

## Возможности

- **Детекция фокуса** — автоматическое переключение темы при потере концентрации
- **Медитация** — таймер с визуализацией мозговых волн
- **Навигация** — управление жестами (в разработке)

## Требования

- EEG-гарнитура (Muse 2, Muse S, OpenBCI)
- Браузер с поддержкой Web Bluetooth (Chrome, Edge)
- HTTPS (обязательно для Web Bluetooth)

## Подключение

1. Включите гарнитуру
2. Нажмите "Подключить" и выберите устройство
3. Дождитесь стабильного сигнала
4. Наслаждайтесь управлением мыслями!
