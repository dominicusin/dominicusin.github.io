Метавселенная платформы: 3D пространства для встреч, VR поддержка через WebXR, галерея NFT.

## Возможности

- **3D Spaces** — виртуальные комнаты для встреч и мероприятий
- **VR Support** — поддержка WebXR для VR-гарнитур
- **NFT Gallery** — галерея достижений и коллекционных NFT
- **Spatial Audio** — пространственный звук для мероприятий
- **Virtual Events** — виртуальные конференции и хакатоны
