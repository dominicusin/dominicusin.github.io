This blog uses a minimal, privacy-friendly social layer:

- **Comments** run on [giscus](https://giscus.app), backed by GitHub
  Discussions. No third-party comment tracking — you comment with your GitHub
  account. Each technical post has its own thread (category *Announcements*).
- **Subscription** uses [Buttondown](https://buttondown.email) for an email
  digest of new material. The form is at the end of every post and on this page.

## Discussion norms

1. Stay on topic and be respectful. Critique ideas, not people.
2. Use code blocks for snippets; markdown is supported.
3. Questions about a post belong in that post's thread (GitHub Discussion).
4. RFC-style proposals are welcome — open a Discussion and link the post.
