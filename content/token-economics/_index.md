Токенизация контента и сообщества. KNOW токен для управления, SBT для достижений, NFT для постов.

## Токены

| Токен | Тип | Назначение |
|-------|-----|------------|
| KNOW | ERC20 | Governance + Utility |
| SBT | ERC721 | Достижения (soulbound) |
| NFT | ERC721 | Коллекционные посты |

## Механики

- **Стейкинг KNOW** → доступ к премиум-контенту
- **Минт SBT** за контрибьюции
- **NFT-посты** с роялти
- **Лояльность** токены для читателей
