# dominicusin.github.io

Domini's site - персональный сайт/блог на базе Jekyll.

## Описание

Это статический веб-сайт, построенный с использованием генератора статических сайтов **Jekyll**. Сайт включает в себя:

- 📝 Блог с постами
- 👤 Страницы о проекте и участниках
- 🏷️ Категории и теги для организации контента
- 🔍 Поиск по сайту
- 📱 Адаптивный дизайн

## Структура проекта

```
├── _domini/      # Данные о доменах
├── _includes/    # Переиспользуемые компоненты шаблона
├── _layouts/     # Шаблоны страниц
├── _people/      # Информация о людях
├── _posts/       # Посты блога
├── _sass/        # Стили Sass
├── _uploads/     # Загруженные файлы
├── assets/       # Статические ресурсы (CSS, JS, изображения)
├── css/          # Стили CSS
└── js/           # JavaScript файлы
```

## Основные файлы

- `index.html` - Главная страница
- `about.md` - Страница "О проекте"
- `archive.html` - Архив публикаций
- `categories.html` - Страница категорий
- `tags.html` - Страница тегов
- `_config.yml` - Конфигурация Jekyll
- `Gemfile` - Зависимости Ruby/Gem

## Технологии

- **Jekyll** - Генератор статических сайтов
- **Sass** - Препроцессор CSS
- **GitHub Pages** - Хостинг сайта

## Локальная разработка

1. Установите зависимости:
   ```bash
   bundle install
   ```

2. Запустите локальный сервер:
   ```bash
   bundle exec jekyll serve
   ```

3. Откройте браузер по адресу: `http://localhost:4000`

## Развёртывание

Сайт автоматически развёртывается на GitHub Pages при пуше в репозиторий.
